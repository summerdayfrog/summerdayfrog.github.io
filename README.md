# august archive

좋았던 영상, 음악, 영화, 책의 후기를 카드로 모아두는 개인 사이트예요.

- `index.html` — 사이트 화면
- `reviews.js` — 기록 데이터 (이 파일만 바꾸면 사이트 내용이 바뀌어요)

## 처음 올리기 (GitHub Pages)

1. [github.com](https://github.com)에 가입해요.
2. 오른쪽 위 **+ → New repository**를 눌러요.
   - Repository name: `내아이디.github.io` (예: 아이디가 `summerdayfrog`이면 `summerdayfrog.github.io`)
   - **Public** 선택 → **Create repository**
3. 만들어진 저장소에서 **uploading an existing file**(또는 **Add file → Upload files**)을 누르고, `index.html`, `reviews.js`, `README.md`를 끌어다 놓은 뒤 **Commit changes**.
4. **Settings → Pages**에서 Branch가 `main` / `(root)`인지 확인하고 **Save**.
5. 1~2분 뒤 `https://내아이디.github.io` 로 들어가면 사이트가 보여요.

## 기록 추가하기

사이트 주소 뒤에 `#edit`을 붙여서 열면 편집 모드가 돼요. → `https://내아이디.github.io/#edit`
**+ 새 기록**으로 쓰고, 카드의 **수정 / 삭제**로 고쳐요.

쓰는 중인 글은 자동으로 임시 저장돼요(작성 화면 아래 "임시 저장됨 00:00"). 저장하지 않고 닫거나, 다른 탭에 다녀오거나, 페이지가 새로 열려도 다시 열면 쓰던 내용이 돌아와요. 새로 쓰고 싶으면 위쪽의 **처음부터 쓰기**를 누르면 돼요. 임시 저장은 그 기기·브라우저에만 남아요.

### GitHub와 연결하기 (처음 한 번)

연결해 두면 기록을 저장·수정·삭제할 때마다 사이트가 `reviews.js`를 알아서 고쳐 올려요. 파일을 내려받아 다시 올릴 필요가 없어요.

**1) 토큰 만들기** — 이 저장소의 파일만 고칠 수 있는 열쇠예요.

1. GitHub 오른쪽 위 프로필 사진 → **Settings**
2. 왼쪽 목록 맨 아래 **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
   (바로 가기: https://github.com/settings/personal-access-tokens/new)
3. 이렇게 채워요.
   - **Token name**: `감상 노트` (아무 이름이나 괜찮아요)
   - **Expiration**: 사용 기간. **Custom**으로 1년 뒤 날짜를 고르면 편해요. 기간이 끝나면 새로 만들면 돼요.
   - **Repository access**: **Only select repositories** → `내아이디.github.io` 하나만 선택
   - **Permissions**: **Repository permissions**(또는 **Add permissions**)에서 **Contents**를 찾아 **Read and write**로
4. 맨 아래 **Generate token**을 누르고, 나온 토큰(`github_pat_…`)을 복사해요. **이 화면을 벗어나면 다시 볼 수 없어요.**

**2) 사이트에 넣기**

1. `https://내아이디.github.io/#edit`을 열고 노란 칸의 **GitHub 연결**을 눌러요.
2. 토큰을 붙여 넣어요. 아이디·저장소 이름·브랜치(`main`)는 보통 자동으로 채워져 있어요.
3. **연결하기** → 노란 칸에 "✓ GitHub 연결됨"이 뜨면 끝이에요.

이제 기록을 저장하면 "✓ GitHub에 저장됨"이 뜨고, 1~2분 뒤 사이트에 반영돼요.

**토큰 관리 주의**
- 토큰은 그 브라우저에만 저장돼요. 다른 기기(예: 휴대폰)에서도 쓰려면 그 기기에서도 한 번 연결해요. 같은 토큰을 다시 붙여 넣거나 새로 만들어도 돼요.
- 토큰은 비밀번호처럼 다뤄 주세요. **`reviews.js`나 다른 파일에 적지 말고**, 남에게 보여주지 마세요.
- 학교·도서관 컴퓨터처럼 여럿이 쓰는 컴퓨터에서는 연결하지 않거나, 다 쓰고 **연결 해제**를 눌러요.
- 토큰을 잃어버렸거나 의심스러우면 GitHub의 같은 토큰 화면에서 **Delete**로 지우고 새로 만들면 돼요.
- 저장이 안 되면 노란 칸에 이유와 **다시 시도** 버튼이 나와요. 그동안 고친 내용은 브라우저에 보관돼 있어요.

### 연결하지 않고 쓰기

연결하지 않아도 써요. 이 경우 고친 내용은 그 브라우저에만 임시 저장되니, 다 고친 뒤 노란 칸의 **reviews.js 내려받기**를 눌러 받은 파일을 GitHub 저장소에 **Add file → Upload files**로 덮어 올리면 돼요.

### 그 밖에

처음에 들어 있는 ‘예시’ 카드 3장은 편집 모드에서 **예시 지우기**로 한 번에 지울 수 있어요.
카드의 **☆ 즐겨찾기** 버튼을 누르면 즐겨찾기에 들어가고, 필터의 **★ 즐겨찾기**로 모아볼 수 있어요.

## 사이트 문구 바꾸기

제목, 소개 문구 같은 글자는 `reviews.js` 맨 위의 `window.SITE`에 있어요. GitHub에서 `reviews.js`를 열고 연필 아이콘으로 고친 뒤 **Commit changes**를 누르면 돼요.

```js
window.SITE = {
  "title": "august archive",      // 큰 제목 (브라우저 탭 이름도 같이 바뀌어요)
  "eyebrow": "Watch · Listen · Read log",    // 제목 위 작은 글씨
  "intro": "좋았던 영상, 음악, ...",      // 제목 아래 소개 문구
  "footer": "@summerdayfrog"      // 맨 아래 작은 글씨
};
```

- 따옴표 `"` 안의 글자만 바꾸고, 따옴표와 줄 끝 쉼표는 남겨두세요.
- 빈 칸 `""`으로 두면 그 줄은 화면에서 숨겨져요. 예) `"eyebrow": ""`
- `//` 뒤는 설명 메모라서 화면에 안 나와요. 지워도 상관없어요.
- 그 밖의 글자(‘전체 기록’, ‘+ 새 기록’ 등)는 `index.html`에 있어요. GitHub에서 `index.html`을 연필 아이콘으로 열고 Ctrl+F(맥은 ⌘+F)로 바꾸고 싶은 글자를 찾아 고치면 돼요. 다만 `<`, `>` 사이의 코드나 따옴표는 건드리지 않게 조심하세요.

## 카테고리 바꾸기

카테고리는 `reviews.js` 맨 위의 `window.CATEGORIES` 목록에 있어요. GitHub 저장소에서 `reviews.js`를 열고 오른쪽 위 **연필(Edit) 아이콘**을 눌러 바로 고친 뒤 **Commit changes**를 누르면 돼요.

```js
window.CATEGORIES = [
  { "id": "video", "label": "영상" },
  { "id": "music", "label": "음악" },
  ...
];
```

- **이름만 바꾸기**: `label`만 고쳐요. 예) `"label": "영상"` → `"label": "유튜브"`. 기존 기록도 그대로 따라와요.
- **새로 추가하기**: 한 줄을 추가해요. `id`는 영문·숫자로 겹치지 않게. 예) `{ "id": "podcast", "label": "팟캐스트" },`
- **순서 바꾸기**: 줄 순서를 바꾸면 필터와 작성 화면의 순서도 바뀌어요.
- **지우기**: 그 줄을 지워요. 그 카테고리였던 기록은 사라지지 않고, `id` 이름 그대로 필터에 남아요. 편집 모드에서 그 기록들의 분류를 다른 걸로 바꿔 주면 정리돼요.
- **`id`는 바꾸지 마세요.** 기록은 `id`로 카테고리와 연결돼서, 바꾸면 기존 기록이 연결을 잃어요. 이름을 바꾸고 싶을 땐 `label`만 고치면 돼요.
- 각 줄 끝의 쉼표(`,`)와 따옴표(`"`)를 지우지 않게 조심하세요. 마지막 줄 뒤에는 쉼표가 없어도 돼요.

### 카테고리별 후기 양식

카테고리에 `template`을 붙이면, 그 카테고리로 **새 기록**을 쓸 때만 후기 칸에 양식이 미리 채워져요. 지금은 `영화·드라마`와 `책`에 들어 있어요.

```js
  { "id": "book", "label": "책",
    "template": [
      "■ 한 줄 요약",
      "",
      "■ 기억에 남는 문장",
      "",
      "■ 내 생각",
      ""
    ]
  },
```

- 한 줄에 하나씩 따옴표 안에 적고, 줄 사이에 쉼표를 넣어요. `""`는 빈 줄이에요.
- 양식에 적은 줄(비어 있지 않은 줄)은 사이트에서 파란 소제목으로 보여요. `⁋제목`, `✓후기`처럼 어떤 기호를 써도 돼요. `■`로 시작하는 줄은 `■`를 떼고 보여줘요.
- 채우지 않은 소제목 항목은 저장할 때 자동으로 빠져요.
- 이미 쓴 기록을 수정할 땐 양식이 끼어들지 않아요. 필요하면 후기 칸 위의 **양식 넣기**를 누르면 돼요.
- 양식이 필요 없는 카테고리는 `template` 부분 없이 `{ "id": "...", "label": "..." }`만 두면 돼요.

### 카테고리별 추가 항목 (입력칸)

양식이 후기 칸 안에 글자를 미리 채워 주는 거라면, `fields`는 그 카테고리를 고를 때만 **입력칸 자체**를 새로 만들어요.

```js
  { "id": "film", "label": "영화·드라마",
    "fields": [
      { "id": "year", "label": "제작연도", "type": "number" },
      { "id": "cast", "label": "출연" }
    ]
  },
```

- `id`는 영문으로 겹치지 않게, `label`은 화면에 보이는 이름이에요.
- `type`은 생략하면 한 줄 칸이에요. `"long"`은 여러 줄 칸, `"number"`는 숫자 칸, `"date"`는 날짜 칸이에요.
- 하위 카테고리에도 붙일 수 있고, 양식처럼 가장 깊은 단계의 것을 써요. ‘유튜브’에 붙이면 ‘유튜브 › 픽셀리 › 잠뜰’에서도 같은 칸이 나와요.
- 적은 값은 카드에 짧게(`출연 잠뜰, 각별`), 크게 보기 화면에는 전부 보여요. 검색에도 걸려요.
- 분류를 바꿔도 이미 적은 값은 기억해 두었다가, 다시 그 분류로 돌아오면 그대로 나와요.

`"bodyLabel": "기억"`처럼 적으면 그 카테고리에서 ‘후기’ 칸의 이름이 바뀌어요.

### 하위 카테고리

카테고리에 `sub`를 붙이면 그 아래에 하위 카테고리가 생겨요. 예) 영상 → 강의·지식 / 브이로그

```js
  { "id": "video", "label": "영상",
    "sub": [
      { "id": "lecture", "label": "강의·지식" },
      { "id": "vlog", "label": "브이로그" }
    ]
  },
```

- 하위 카테고리도 카테고리와 같은 규칙이에요. `id`는 영문으로 겹치지 않게 정하고 바꾸지 않아요. `label`은 자유롭게 바꿔도 돼요.
- 기록을 쓸 때 그 카테고리를 고르면 **세부 분류** 칸이 나타나요. ‘선택 안 함’으로 둬도 돼요.
- 사이트에서 그 카테고리를 누르면 아래 줄(└)에 하위 카테고리가 나와서 한 번 더 골라 볼 수 있어요. 아직 기록이 없는 카테고리는 흐리게 보여요.
- 카드에는 `영상 · 강의·지식`처럼 함께 표시돼요.
- 하위 카테고리에도 `template`을 붙일 수 있어요. 붙이면 카테고리 양식 대신 그 양식이 나와요.

```js
      { "id": "lecture", "label": "강의·지식",
        "template": ["■ 핵심 내용", "", "■ 새로 알게 된 것", ""] },
```

#### 하위의 하위 카테고리

하위 카테고리 안에 다시 `sub`를 넣으면 한 단계 더 내려가요. 몇 단계든 같은 방식이에요.

```js
  { "id": "video", "label": "영상",
    "sub": [
      { "id": "lecture", "label": "강의",
        "sub": [
          { "id": "math", "label": "수학" },
          { "id": "science", "label": "과학" }
        ]
      },
      { "id": "vlog", "label": "브이로그" }
    ]
  },
```

- 기록을 쓸 때 ‘강의’를 고르면 그 아래에 ‘수학 / 과학’을 고르는 칸이 하나 더 생겨요. 중간에서 멈추고 ‘더 나누지 않음’으로 둬도 돼요.
- 필터도 한 단계씩 아래 줄로 내려가며 보여요. ‘강의’를 고르면 수학·과학 기록이 모두 보이고, ‘수학’을 고르면 수학만 보여요.
- 양식은 가장 깊은 단계에 있는 것부터 써요. ‘수학’에 양식이 없으면 ‘강의’ 양식, 그것도 없으면 ‘영상’ 양식이 나와요.
- `id`에는 `/`를 쓰지 마세요. 기록에는 `"sub": "lecture/math"`처럼 `/`로 이어서 저장되기 때문이에요.
- 단계가 너무 깊으면 고르기 번거로워져요. 2~3단계 정도가 쓰기 편하고, 그보다 잘게 나누고 싶으면 태그를 같이 쓰는 걸 추천해요.

**참고**: GitHub와 연결해 두면 편집 모드가 늘 GitHub의 최신 `reviews.js`를 읽어와서, GitHub에서 직접 고친 문구·카테고리가 덮어써지지 않아요. 연결하지 않고 ‘내려받기’로 쓸 때는, 카테고리를 GitHub에서 고친 뒤 반영된 사이트를 새로 열고 나서 기록을 편집·내려받으세요.

## 나만 보기

### 방법 A: 기록을 비공개 저장소로 옮기기 (토큰이 있는 기기에서만 보임)

사이트 화면(`index.html`)만 공개 저장소에 두고, 기록(`reviews.js`)은 Private 저장소에 둬요. 토큰이 없는 사람이 사이트에 들어오면 "잠긴 노트" 화면만 보여요.

1. **비공개 저장소 만들기**: + → New repository → 이름 `notes`(아무거나) → **Private** → Create repository
2. **기록 옮기기**: 지금 공개 저장소의 `reviews.js`를 열고 오른쪽 위 **다운로드 아이콘(Download raw file)**으로 받아요. 새 `notes` 저장소에 **uploading an existing file**로 올려요. 이 README.md도 여기에 같이 두면 좋아요.
3. **토큰 고치기**: Settings → Developer settings → Fine-grained tokens → 내 토큰 → **Edit** → Repository access에서 `notes`를 선택 → Contents가 Read and write인지 확인 → **Update**
4. **공개 저장소 새로 만들기**: 공개 저장소에는 예전 `reviews.js` 기록이 히스토리로 남아 있어서, 지우고 새로 만드는 게 깔끔해요.
   - `아이디.github.io` 저장소 → Settings → 맨 아래 **Delete this repository**
   - 같은 이름으로 Public 저장소를 다시 만들고, **`index.html` 하나만** 올려요.
   - Settings → Pages에서 Branch가 `main` / `(root)`인지 확인
5. **연결하기**: 사이트를 열면 "잠긴 노트" 화면이 나와요. **GitHub 연결** → 토큰 붙여 넣기 → 저장소 이름에 `notes` → 연결하기
   - 예전에 연결해 둔 기기는 `#edit`에서 **연결 해제** 후 같은 방법으로 다시 연결해요.

이제 기록을 쓰면 `notes` 저장소의 `reviews.js`에 저장돼요. 문구·카테고리·양식도 `notes` 저장소의 `reviews.js`에서 고치면 돼요. 기기마다 한 번씩 연결해야 보여요.

### 방법 B: 주소만 안 알려주기

지금 구조 그대로 두고, 주소를 아무에게도 알려주지 않는 방법이에요. `index.html`에 검색엔진에 나오지 않게 하는 설정이 들어 있어요. 다만 GitHub 프로필에서 저장소를 찾아 들어오면 사이트와 `reviews.js` 내용을 볼 수 있어요.

## 휴대폰에 앱으로 설치하기

크롬(안드로이드)에서 메뉴 → **앱 설치**(또는 홈 화면에 추가), 아이폰 사파리에서는 공유 → **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있어요.
아래 파일들이 `index.html`과 같은 곳(공개 저장소)에 있어야 아이콘과 시작 화면이 또렷하게 나와요.

- `manifest.webmanifest` — 앱 이름·바탕색·아이콘 설정
- `app-icon-192.png`, `app-icon-512.png` — 시작 화면에 뜨는 아이콘 (투명 배경)
- `app-maskable-512.png` — 안드로이드 홈 화면 아이콘 (하늘색 바탕)
- `icon-32.png`, `icon-192.png`, `apple-touch-icon.png` — 탭 아이콘·아이폰 홈 화면 아이콘

앱 이름을 바꾸려면 `manifest.webmanifest`의 `"name"`, `"short_name"`을 고쳐요. 이미 설치한 앱은 지웠다가 다시 설치해야 바뀐 아이콘·이름이 반영돼요.

## 알아두면 좋은 것

- **유튜브 썸네일**은 링크의 `v=` 뒤(또는 `youtu.be/` 뒤, `shorts/` 뒤)에 있는 11자리 영상 코드로 자동으로 불러와요. 링크 끝의 `si=...`는 공유 추적값이라 상관없어요.
- 영상이 아닌 기록은 **커버 이미지 주소** 칸에 이미지 주소를 넣으면 그 이미지가 커버가 돼요. 비워두면 색 커버가 붙어요.
- `#edit`은 편집 버튼을 숨겨두는 장치일 뿐이에요. 다른 사람이 `#edit`으로 들어와도 토큰이 없으면 그 사람 브라우저에만 남고, 실제 사이트는 토큰을 가진 사람만 바꿀 수 있어요.
- 컴퓨터에서 `index.html`을 더블클릭해도 미리 볼 수 있어요.
